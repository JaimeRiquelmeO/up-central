# Checklist de entrega

## Solicitud

- [ ] Ramo, contenidos y nivel confirmados.
- [ ] Cantidad y dificultad de ejercicios confirmadas.
- [ ] Formato del solucionario confirmado.
- [ ] Referencias revisadas.

## Contenido

- [ ] Todos los ejercicios tienen datos suficientes.
- [ ] No existen hipótesis contradictorias o ambiguas.
- [ ] La numeración coincide entre ejercicios y solucionario.
- [ ] Dominios, unidades y aproximaciones están declarados.
- [ ] La progresión de dificultad es coherente.

## Validación

- [ ] Existe una prueba por cada resultado visible.
- [ ] Se usó aritmética exacta cuando correspondía.
- [ ] Cada cálculo relevante tiene dos comprobaciones independientes.
- [ ] Se probaron restricciones y casos especiales.
- [ ] `python validar_resultados.py` termina con todas las pruebas aprobadas.

## PDF

- [ ] LaTeX compila dos veces sin errores.
- [ ] Todas las páginas fueron renderizadas y revisadas.
- [ ] No hay texto cortado, superpuesto o fuera de margen.
- [ ] Encabezados, pies, logos y numeración son consistentes.
- [ ] `pypdf` y `pdfplumber` pueden abrir y extraer texto del PDF.
- [ ] El PDF no menciona herramientas internas de validación.
