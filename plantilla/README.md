# Kit para crear y validar guías

Esta carpeta permite crear una guía académica desde cero siguiendo el estilo de Usach Premium y el estándar de validación usado en este repositorio.

## Elige una modalidad

### 1. `crear-y-validar-guias-en-codigo`

Para trabajar directamente en este repositorio con Codex, Visual Studio Code u otro editor. Incluye reglas automáticas, formulario de contexto, plantilla LaTeX, validador Python y script de construcción.

### 2. `archivos-para-chatgpt-web`

Paquete autocontenido para subir sus archivos a ChatGPT desde el navegador. Incluye un prompt maestro, formulario de solicitud, contexto institucional, plantilla LaTeX, logos, ejemplo visual y base de validación.

La misma carpeta está disponible lista para compartir como `paquete-chatgpt-web.zip`.

## Estándar obligatorio

Una guía no está terminada hasta que:

1. cada ejercicio tenga una respuesta inequívoca;
2. cada resultado haya sido comprobado mediante Python;
3. los cálculos relevantes cuenten con dos métodos independientes y, cuando corresponda, una tercera comprobación;
4. el PDF compile sin errores y sea revisado página por página;
5. el documento no mencione Python, inteligencia artificial ni herramientas internas.

Consulte [GUIA_DE_USO.md](./GUIA_DE_USO.md) para el flujo completo.
