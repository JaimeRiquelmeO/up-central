# Archivos para usar en ChatGPT web

## Qué subir

Suba juntos estos archivos al mismo chat:

1. `PROMPT_MAESTRO.txt`
2. `FORMULARIO_SOLICITUD.md`, previamente completado
3. `CONTEXTO_Y_REGLAS.md`
4. `plantilla_guia.tex`
5. `validar_resultados.py`
6. `requirements.txt`
7. `images/logo_up.png`
8. `images/logo_usach.png`
9. `ejemplo_visual_guia.pdf`
10. cualquier prueba, pauta, apunte o guía de referencia del ramo

Si la interfaz limita la cantidad de archivos, comprima toda esta carpeta como ZIP y adjunte además `FORMULARIO_SOLICITUD.md` y `PROMPT_MAESTRO.txt` por separado.

## Orden recomendado

1. Complete el formulario.
2. Inicie un chat nuevo.
3. Suba todos los archivos.
4. Pegue el contenido de `PROMPT_MAESTRO.txt`.
5. Responda las preguntas que ChatGPT formule antes de crear la guía.
6. Pida como entrega: fuente LaTeX, PDF final y script Python ejecutado.
7. No acepte una declaración genérica de validación: solicite el resumen de pruebas aprobadas por ejercicio.

## Resultado esperado

- `main.tex` o equivalente;
- PDF final con el estilo visual del ejemplo;
- `validar_resultados.py` completo;
- reporte breve de correcciones de enunciados y cantidad de pruebas aprobadas.
