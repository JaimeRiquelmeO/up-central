Quiero que uses todos los archivos adjuntos como un paquete de trabajo para crear una guía académica nueva o para revisar una guía que ya está realizada.

DETECCION DEL MODO DE TRABAJO
1. Primero determina si solicito CREAR una guía nueva o VALIDAR una guía existente.
2. Si no es evidente, pregúntame cuál de los dos modos necesito antes de continuar.
3. Si adjunto una guía ya realizada, pregúntame expresamente: "¿Quieres que valide con Python todos los ejercicios y resultados de esta guía para comprobar si son correctos?"
4. No ejecutes correcciones ni reemplaces respuestas hasta que te indique si quiero solamente un informe de validación, una versión corregida de la fuente o también un PDF final corregido.

MODO VALIDAR UNA GUIA EXISTENTE
1. Lee la guía completa, incluyendo enunciados, alternativas, tablas, figuras, solucionario y notas.
2. Crea un inventario de todos los ejercicios y subítems que tengan una respuesta verificable.
3. Comprueba primero que cada enunciado sea suficiente, coherente y matemáticamente posible. Separa los errores de enunciado de los errores de respuesta.
4. Si confirmo la validación con Python, crea y ejecuta validar_resultados.py. Debe existir al menos una prueba por cada resultado visible.
5. Usa al menos dos métodos independientes cuando sea viable: por ejemplo SymPy para el resultado exacto y NumPy/SciPy, fractions, math, sustitución directa, enumeración o simulación como segunda comprobación.
6. Revisa dominios, unidades, redondeos, casos degenerados, soluciones espurias y consistencia entre enunciado y solucionario.
7. Clasifica cada elemento como CORRECTO, INCORRECTO, ENUNCIADO INCONSISTENTE o NO VERIFICABLE CON LOS DATOS DISPONIBLES.
8. Entrégame un informe con el resultado correcto, la diferencia encontrada y la justificación de cada error. No modifiques la guía si solo pedí validarla.
9. Si solicito correcciones, actualiza la fuente conservando el estilo original, vuelve a ejecutar todas las pruebas y genera el PDF corregido solo si también lo pedí.
10. No afirmes que "todo está validado" si falta revisar algún ejercicio o si alguna prueba no fue ejecutada.

MODO CREAR UNA GUIA NUEVA

Antes de crearla:
1. Lee completamente FORMULARIO_SOLICITUD.md, CONTEXTO_Y_REGLAS.md y la plantilla LaTeX.
2. Revisa el PDF de ejemplo para reproducir su lenguaje visual, sin copiar su contenido académico.
3. Pregúntame siempre si tengo pruebas, controles, pautas, guías o evaluaciones de años anteriores que pueda adjuntar como referencia para conocer el estilo, la dificultad, la notación y el tipo de ejercicios esperados.
4. Si tengo material de años anteriores, espera a que lo adjunte y revísalo antes de diseñar la nueva guía. Úsalo como referencia académica, pero no copies ejercicios de forma literal salvo que yo lo solicite expresamente.
5. Si no tengo material anterior, indícalo en el resumen de configuración y continúa usando los contenidos y requisitos proporcionados.
6. Si faltan el ramo, los contenidos, la cantidad de ejercicios, la dificultad o el tipo de solucionario, pregúntame esos datos antes de continuar.
7. Resume la configuración acordada y diseña un inventario de ejercicios con identificadores E1, E2, etc.

Luego:
1. Crea ejercicios originales, suficientes y sin ambigüedades, con progresión de dificultad adecuada.
2. Crea el solucionario solicitado y conserva correspondencia exacta con los ejercicios.
3. Adapta plantilla_guia.tex y utiliza los logos adjuntos.
4. Implementa validar_resultados.py con una prueba para cada ejercicio o subítem evaluado.
5. Valida los cálculos con Python. Usa al menos dos métodos independientes por resultado cuando sea viable: por ejemplo SymPy para forma exacta y NumPy/SciPy, fractions, math, sustitución, enumeración o simulación como comprobación separada.
6. Verifica dominios, unidades, redondeos, casos especiales y soluciones espurias.
7. Ejecuta el validador. Si algo falla, corrige el enunciado, el desarrollo o la respuesta y vuelve a ejecutar.
8. Compila el PDF dos veces, renderiza todas las páginas y revisa visualmente el resultado.
9. Verifica el PDF con pypdf y pdfplumber.

Entrégame:
- el PDF final;
- la fuente LaTeX;
- el archivo Python de validación;
- un resumen externo al PDF indicando cuántas pruebas pasaron y qué inconsistencias fueron corregidas.

No escribas dentro de la guía o del PDF que se usó Python, inteligencia artificial o herramientas de validación. Esa información es exclusivamente interna.
