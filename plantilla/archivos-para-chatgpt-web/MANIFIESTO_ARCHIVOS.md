# Manifiesto del paquete web

| Archivo | Propósito |
|---|---|
| `PROMPT_MAESTRO.txt` | Instrucción que se pega en el chat. |
| `FORMULARIO_SOLICITUD.md` | Define ramo, contenidos, cantidad y dificultad. |
| `CONTEXTO_Y_REGLAS.md` | Estándar institucional, académico y de validación. |
| `plantilla_guia.tex` | Base visual y estructural compilable. |
| `validar_resultados.py` | Base que obliga a cubrir cada resultado con dos métodos. |
| `requirements.txt` | Librerías Python recomendadas. |
| `images/logo_up.png` | Logo institucional izquierdo. |
| `images/logo_usach.png` | Logo institucional derecho. |
| `ejemplo_visual_guia.pdf` | Referencia de acabado visual. |

Los apuntes, pruebas o pautas propios del nuevo ramo se agregan a este paquete antes de iniciar el chat.
